NexusOS 1.4

- Updates: NexusOS now updates itself from Settings > Updates. Every update is checked against your own signing key before anything changes, installs beside the current version, and you can go back with one button. If a new version ever fails to start, NexusOS goes back by itself.
- NVIDIA: the open-source nouveau driver can no longer grab the graphics card before NVIDIA's driver. Settings > Security & privacy shows whether the NVIDIA driver is running, with a fix button if it isn't.
- Secure Boot: the "let Secure Boot trust the NVIDIA driver" button now appears whenever it's needed.
- Wi-Fi: a power-saving switch in Settings > Wi-Fi. Turn it off for steadier download speeds.
- Terminal: Ctrl+V pastes (Ctrl+C still stops a running command).
